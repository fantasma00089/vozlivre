# VozLivre

App de comunicação para grupos: voz, chat de texto e compartilhamento de tela,
rodando em servidor próprio.

## Baixar

O instalador de cada versão está em [Releases](../../releases/latest).
Windows, instala sem pedir administrador.

Para usar você precisa do **endereço do servidor** e da **senha de acesso** de
quem te convidou — o app não se conecta a lugar nenhum sozinho.

## Como funciona

Voz e tela vão **direto entre os participantes** (WebRTC ponto a ponto). O
servidor cuida apenas de contas, mensagens e de apresentar os participantes uns
aos outros.
